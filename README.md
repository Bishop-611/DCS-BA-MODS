# DCS-BA-MODS

DCS World and Heatblur F-4E mods by Bishop-611.

| Project | Description | Download |
| --- | --- | --- |
| [FOX SENSE](FOX%20SENSE/README.md) | Situational-awareness overlay | [0.10.14](https://github.com/Bishop-611/DCS-BA-MODS/releases/tag/fox-sense-v0.10.14) |
| [F4E Modern Avionics](F4E%20modernization/README.md) | Radar, HUD, CCIP/CCRP and RWR modernization | [1.3.4](F4E%20modernization/F4E-Modern-Avionics-1.3.4.exe) |
| [F4E-Niko WSO](F4E-Niko%20WSO/README.md) | Rear-seat character, voice, music and livery bundle | [v12.2](https://github.com/Bishop-611/DCS-BA-MODS/releases/tag/f4e-niko-wso-v12.2) |

Modern Avionics 1.3.4 calibrates the HUD pitch ladder and flight-path marker, reduces repeated HUD display elements, and updates AGM-88 release compatibility. Both installer and manual downloads are available.

Close DCS before installation and keep each installer's backups. Follow the project guides above. With Niko WSO installed, leave FOX SENSE's optional portrait replacement disabled.
