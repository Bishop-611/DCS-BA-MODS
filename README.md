DCS World and Heatblur F-4E mods by Bishop-611.

| Project | Description | Download |
| --- | --- | --- |
| [FOX SENSE](FOX%20SENSE/README.md) | Situational-awareness overlay | [0.10.13](https://github.com/Bishop-611/DCS-BA-MODS/releases/tag/fox-sense-v0.10.13) |
| [F4E Modern Avionics](F4E%20modernization/README.md) | Radar, HUD, CCIP/CCRP and RWR modernization | [1.2.36](F4E%20modernization/F4E-Modern-Avionics-1.2.36.exe) |

Modern Avionics 1.2.36 updates cockpit display controls, TV page switching and the RWR audio test. Both installer and manual downloads are available.

Close DCS before installation and keep each installer's backups. Follow the project guides above. With Niko WSO installed, leave FOX SENSE's optional portrait replacement disabled.
