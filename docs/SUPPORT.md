# Support

[Back to projects](../README.md)

[Open an issue](https://github.com/Bishop-611/DCS-BA-MODS/issues/new/choose) and include:

- Project and package version, including whether it came from a public download or a local build.
- DCS version, aircraft, and single-player or multiplayer environment.
- Expected result, actual result and reproducible steps.
- Installation method, selected profile, and other mods affecting the same files.
- Relevant error text or a short log excerpt; screenshots when useful.

Remove personal information and credentials before uploading diagnostics. Do not upload the entire maintenance workspace or game backups.

For installation conflicts, preserve the reported files and backups. Use the matching installer restoration process rather than overwriting shared scripts. For FOX SENSE, verify the Saved Games profile, server export permissions and that all bridge/runtime components were updated together.
