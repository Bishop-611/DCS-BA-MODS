## Release conventions

Use project-specific tags: `fox-sense-v<version>`, `f4e-modern-avionics-v<version>`, and `f4e-niko-wso-v<version>`. Each release should include installation packages, checksums, concise English changes, installation/restore instructions and the applicable DCS baseline.

A new package must receive a new version. Do not silently replace a delivered binary with different code under the same version. Verify uploaded assets and checksums before updating download tables. An accepted local build and a published download are different states.

Keep historical release tags and download links working. New binary distributions should use GitHub Releases. The existing Modern Avionics 1.1.36 repository download remains available for compatibility with existing links.

GitHub's global Latest label applies to one release in this multi-project repository. Always use the per-project table.
