FOX SENSE 0.10.14

Run FOX-SENSE-0.10.14-Setup.exe with DCS and FOX SENSE closed.
Choose your active DCS Saved Games profile and Install / Update.
Check the Jester mods location when using F-4E integration.
Leave optional portrait replacement unchecked when using Niko WSO.
Keep Backups, install-manifest.json and your settings.

This installer accepts a portrait that exactly matches its saved original backup.
Unknown changes remain protected. Runtime unchanged from 0.10.13.
For manual installation, follow the README inside the separate Manual.zip.
Do not overwrite other mods or restore a whole old Export.lua over later edits.
