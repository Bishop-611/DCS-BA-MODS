F4E-Niko WSO v11 - Installation and restoration

1. Close DCS and run F4E-Niko.WSO.exe.
2. Select the DCS World installation containing the Heatblur F-4E and the active Saved Games profile.
3. Choose Install All to install or upgrade the character, portrait, voice, music and livery together.
4. Keep NikoWSO_Backups in the DCS installation. To uninstall, close DCS, select the same installation/profile, and choose Restore All.

Repeat installation preserves the original backups. Unsupported files or conflicting edits stop installation. Review the named file before retrying; do not overwrite another mod's changes or restore an entire old shared Lua file.

If using FOX SENSE, leave its optional portrait replacement unchecked. The installer does not install FOX SENSE or Modern Avionics.
