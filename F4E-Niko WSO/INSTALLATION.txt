# F4E-Niko WSO v9

Fixes the floating rear-seat safety straps that continued following the original WSO skeleton. Duplicate original rear Koch strap meshes are removed; Niko's own harness is retained.

- Keeps the approved warm textures, saturated pink hair and normal day/night face lighting.
- Keeps hair shadow casting disabled; no face self-illumination is added.
- Keeps all eight dedicated rear ejection personnel/occupied-seat models and their native animation graphs.
- Front-seat straps, generic DCS pilots, front-seat ejected personnel and avionics are unchanged.
- Includes the existing portrait, Jester voice, Tape Player and FOX PLATOON v0.13 livery.

## Install and restore

Close DCS, run **F4E-Niko-WSO-v9.exe**, select the DCS installation and active Saved Games profile, then choose **Install All**. Keep **NikoWSO_Backups** and use **Restore All** to undo the package. All interface text and messages are in English.

Supported previous versions and the approved temporary harness fix are accepted. Original model restoration baselines are retained, and unrelated avionics script content is preserved when merging Niko's marked script sections.

The four changed seated/cockpit model files remove only the duplicate rear strap meshes. Other geometry, material properties, animation nodes and connectors are unchanged. All other v8 payload resources are retained unchanged.

In-game ejection landing/movement behavior is not newly verified. External Jester animation troubleshooting remains deferred.
