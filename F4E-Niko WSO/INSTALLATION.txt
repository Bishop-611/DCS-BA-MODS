# F4E-Niko WSO v8

This complete package combines the approved warm character textures, disabled hair shadow casting, and dedicated rear WSO ejection models.

- Warm skin and saturated pink hair retain their brightness; no global darkening is applied.
- Hair no longer casts shadows. Faces remain normally lit and darken at night; no face self-illumination was added.
- Dedicated rear ejection personnel and occupied ejection seats are replaced at all four native LODs. Original animation nodes, bones, connectors and non-character seat/parachute geometry are retained.
- Generic DCS pilots and front-seat ejected pilots are not replaced. No avionics changes are included.
- Existing portrait, voice, Tape Player and FOX PLATOON v0.13 livery components remain included.

## Installation

Close DCS, run **F4E-Niko-WSO-v8.exe**, select the DCS installation and the active Saved Games profile, and choose **Install All**. Keep **NikoWSO_Backups** for **Restore All**. The interface and messages are in English.

The installer accepts supported prior Niko versions and the approved temporary texture/hair-shadow preview. Unknown model changes are refused. Shared cockpit scripts are merged only within Niko's marked sections, preserving other avionics modifications. Original ejection models are included for exact restoration.

## Verification and limits

Warm textures and hair-shadow changes were accepted after a temporary game installation. Ejection exports preserve native animation graphs and non-character geometry; their actual in-game landing/movement behavior has not been newly verified. Native animation preservation does not prove every post-landing object remains the same model. No generic pilot replacement is used to work around that limitation.

External Jester animation troubleshooting was explicitly deferred and is not presented as fixed by this release.
